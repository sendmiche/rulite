## ❤️ RULITE — geosite.dat и geoip.dat для России

⚡ Автоматическая сборка облегчённых файлов `geosite.dat` и `geoip.dat` в течение часа после выхода релиза [runetfreedom/russia-v2ray-rules-dat](https://github.com/runetfreedom/russia-v2ray-rules-dat) — только если файлы действительно изменились.

🧠 Основано на:

* [@v2fly/domain-list-community](https://github.com/v2fly/domain-list-community)
* [Antifilter](https://antifilter.network/)
* [re:filter](https://github.com/1andrevich/Re-filter-lists)

🧪 В файлах оставлены только актуальные категории:

* `geosite.dat` — 303.2 КБ
* `geoip.dat` — 409.1 КБ

✅ Отлично подходит для пользователей из России для Happ и INCY
